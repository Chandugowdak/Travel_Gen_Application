# Copilot Project Instructions

This project contains two main folders:
- `frontend/` — React + Vite app using JSX, CSS, HTML, and JavaScript
- `backend/` — Node.js + Express + MongoDB/Mongoose API using JavaScript

## Technologies and tags to include
- JS
- React
- JSX
- Vite
- HTML
- CSS
- Node.js
- Express
- MongoDB
- Mongoose
- JWT
- bcrypt
- dotenv
- CORS
- API
- JSON
- Markdown

## Guiding conventions
- Use modern ES module syntax: `import` / `export` / `export default`
- Prefer React functional components and hooks in the frontend
- Keep backend controllers, routes, models, and middleware separate and consistent
- Preserve the existing frontend/backend folder structure
- Use clear camelCase naming for variables, functions, props, and routes
- Keep UI text and JSX content readable and maintain the project's text tags

## When generating or editing code
- Match the current project style and conventions
- Use React components and JSX for frontend UI
- Use Express route handlers and controller functions for backend logic
- Keep configuration and environment usage compatible with `Vite` and Node
- Include the relevant project tags whenever giving examples or explanations
